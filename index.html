MCP Servers (experimental — llama.cpp stdio)

Expose local tools to the model via --mcp-servers-config (Cursor-compatible mcpServers JSON, stdio transport). The server spawns each command on demand and exposes its tools as server_tool via GET /tools. Only declare servers you trust — they run with the same privileges as llama-server and will limit --cors-origins to localhost.

Server Settings

Launch mode, concurrency, and persistent defaults for the llama.cpp server.

In Router Mode the server exposes every GGUF in the models folder and automatically loads the model requested by each chat message (via the model field). Switching models in the chat UI takes effect immediately, no server restart needed. Requires a recent llama-server build with --models-dir support.

Number of parallel sequences llama-server can process simultaneously.

Higher values allow the server to handle concurrent requests and multiple parallel sequences, but each slot reserves its own KV-cache context memory.

Save the current port, context size, GPU offloading layers (-ngl 99), sampling parameters, extra arguments, and theme as the startup defaults.
